# java-racingcar-precourse

## 과제 개요
사용자가 입력한 자동차 이름과 시도 횟수를 바탕으로,  
각 자동차가 전진할지 멈출지를 랜덤으로 결정하는 **자동차 경주 게임**을 구현한다.  
모든 시도가 끝나면 최종 우승자를 출력한다.

---
## 기능 목록
### 1. 입력
- [ ] 사용자로부터 **자동차 이름 목록**을 입력받는다.
    - 쉼표(,) 기준으로 이름을 분리한다.
    - 각 이름은 **5자 이하**인지 검증한다.
    - 중복되거나 빈 이름이 존재하면 `IllegalArgumentException` 발생.
- [ ] 사용자로부터 **시도 횟수**를 입력받는다.
    - 숫자가 아니거나 1 이하인 경우 예외 발생.

---

### 2. 자동차 초기화
- [ ] 이름을 기반으로 `Car` 객체를 생성하고, 각 자동차의 초기 위치를 0으로 설정한다.

---

### 3. 게임 진행 (경주)
- [ ] 지정된 시도 횟수 동안 모든 자동차에 대해 전진 또는 정지를 반복한다.
- [ ] 전진 조건: `Randoms.pickNumberInRange(0, 9)` 결과가 **4 이상**일 경우 전진.
- [ ] 각 라운드마다 현재 상태를 출력한다.
- 예시
<br>
  pobi : -- <br>
  woni : - <br>
  jun : --- <br>
---

### 4. 우승자 계산
- [ ] 모든 시도가 끝난 후, **최대 이동 거리(position)**를 계산한다.
- [ ] 동일한 최댓값을 가진 자동차가 여러 대일 경우 **공동 우승자**로 처리한다.
- [ ] 결과 예시:
<br>
최종 우승자 : pobi, jun


---

### 5. 출력
- [ ] 각 시도 결과와 최종 우승자를 순서대로 출력한다.
- [ ] 출력 형식을 반드시 요구사항에 맞춘다.  
  (형식 불일치 시 0점 처리)

---

### 6. 예외 처리
- [ ] 잘못된 입력 시 `IllegalArgumentException`을 발생시키고 애플리케이션을 종료한다.
- [ ] `System.exit()` 사용 금지.
- [ ] 예외 메시지는 명확하게 작성한다.
